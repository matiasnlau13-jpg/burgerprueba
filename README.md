# Burger Don · Grill House

Landing de una sola página para tomar pedidos por WhatsApp.

- **Archivo único:** `index.html`. Se abre en cualquier navegador, sin instalar nada.
- **Para editar** nombres, precios, número de WhatsApp, hamburguesas y extras:
  buscá el bloque `CONFIG` al final del archivo, dentro de `<script>`.
- **Fotos de las hamburguesas:** el campo `photo` de cada una acepta un data URI.
  Si queda vacío se usa una ilustración de ejemplo.

## Publicar con GitHub Pages

1. En GitHub: **Settings → Pages**.
2. En *Source* elegí la rama `main` y la carpeta `/ (root)`.
3. Guardá. En un minuto queda online en `https://<usuario>.github.io/<repo>/`.
